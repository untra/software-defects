# Software Defects — a field guide to stateful bugs

An interactive, multilingual static site that teaches the **four families of stateful
software defect** — *mutated*, *unstructured*, *shared*, and *common* — through
narrative, real code across 12 languages, and animated category glyphs.

Built from talks by **Samuel Volin**. This is a rebuild of an earlier pass: redesigned
around a "diagnostic console" aesthetic, given a **fourth defect family**, and fitted
with **Lottie animations**.

Each family is broken out into its **nine constituent defects**, and each defect gets its
**own page** with worked examples and a **generated text-based Lottie** that animates the
defect's name.

The **Bugs of Mutated State** family (green accent `#78A65A`) covers var/let/mut,
**aliasing & mutable defaults**, for-loop control flow, `this` mutation,
time/money/entropy, impure functions, macro/mixin misuse, `++`/`--`, and nonstandard
getters/setters.

The **Common Software Defects** family (gray accent `#94A3B8`) reads as a **3×3** by *how
a defect is caught* — readability (copy-pasta, magic numbers, naming), correctness (DRY /
rule of three, off-by-one, error handling), and security (dependency issues / **SCA**,
injection & taint flaws / **SAST**, runtime & integration flaws / **DAST**).
**Off-by-one lives here, not under mutated state**: it is the boundary bug *every*
stateful tool can produce, so its page shows a generic and a stateful variant across nine
languages.

### `src/` — the generator
- **`content.py`** — the entire defect catalog as Python data: 4 families, 36 child
  defects, 80+ worked examples,
  the cascade narrative, the Knight Capital case file, the human/computer analogy and
  deadlock/livelock and execution-model tables, naming qualities, pull-quote, and the
  recurring "two hard problems" joke. Edit here to change content.
- **`i18n.py`** — UI labels for all six languages. (Domain narrative stays in English by
  design; only chrome is localized.)
- **`highlight.py`** — Pygments-based server-side syntax highlighting + the dark theme.
- **`anim_gen.py`** — programmatic Lottie generator: emits the family glyphs plus one
  text-based animation per child defect, in each family's accent — including the gray
  common-defects set (copy-pasta, magic numbers, off-by-one, …).
- **`anim_static/`** — hand-authored Lottie glyphs for the other three families,
  copied verbatim at build time.
- **`build.py`** — reads the above and writes `../site/`.

## Rebuilding

Requires Python 3.10+.

```bash
cd src
pip install -r requirements.txt
python build.py        # writes ../site/
```

`build.py` emits the full site (family hubs + per-defect child pages), copies assets,
**generates** the mutated-state animations via `anim_gen.py`, copies the other families'
static glyphs, generates the highlight theme, writes `.nojekyll` and `CNAME`, and dumps
`_data/*.yml` for architecture fidelity.

The generated `site/` directory is **not** committed — it is rebuilt by CI on every deploy.

## Design notes

- **Diagnostic-console aesthetic.** Dark "console" surfaces for hero/context bands,
  cool-neutral light surfaces for reading. JetBrains Mono tag-labels are used as a
  structural device. Code examples render as editor windows.
- **Colour carries meaning.** Each family owns an accent — green (mutated), blue
  (unstructured), purple (shared), slate (common) — applied to nav, cards, glyphs,
  per-page accent variables, tables and chips.
- **Lottie glyphs are the signature.** The mutated-state (green) and common-defects (gray) child sets are *typographic*: each
  child defect's animation spells its own name in motion (var→let→mut cycling, the last
  letter of "erro­r" dropping off by one, `this` letting `mutation` drift away, a value
  ticking under `++`/`--`, …), echoing the deck. The other three families keep their
  abstract glyphs — an item pouring into a vessel (unstructured), actors colliding
  around a hub (shared), a duplicated block cracking along a fault line (common). All
  lazy-load on scroll and respect `prefers-reduced-motion` (holding a mid-loop frame).
- **Type & motion** load from Google Fonts and the bodymovin/Lottie CDN at runtime.

## Deploying

Deployment is automated via GitHub Actions (`.github/workflows/deploy.yml`): every push
to `main` builds the site and publishes it to **GitHub Pages** at the custom domain
**https://softwaredefects.untra.io**. The build writes `.nojekyll` (serve files verbatim)
and `CNAME` (the custom domain) into the output. You can also trigger a deploy manually
from the Actions tab (`workflow_dispatch`).

One-time setup (in the GitHub repo):

1. **Settings → Pages → Source = "GitHub Actions".**
2. **DNS:** add a `CNAME` record `softwaredefects` → `untra.github.io` at the `untra.io`
   DNS provider.
3. After the first deploy, enable **"Enforce HTTPS"** in Pages settings.

To host elsewhere (Netlify, Vercel, S3, Cloudflare Pages), build locally and set `site/`
as the publish directory. Links and assets use root-absolute paths, so serve from the
domain root (or adjust the paths if hosting under a sub-path).
